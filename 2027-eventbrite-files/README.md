# 2027 Eventbrite files

Cover images for JobFairX events on Eventbrite, all 2160 x 1080 px (2:1), PNG, with an editable SVG next to each one.

Gallery: https://scottjobagent.github.io/jobfairx-prototype/2027-eventbrite-files/

cover-job-fair.png is the shared cover for an event that runs all five rooms (used by the five Eventbrite template mockups). option-a, option-b and option-c are three design directions for a one-event-type-per-week schedule, five covers each; the option-*-five-weeks.png images show the five side by side.
